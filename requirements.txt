# Legacy of Stars - Requirements
#
# The game uses the Python standard library only. Python 3.9 or newer is required
# (3.12 is what it is developed and tested with).
#
# No packages need to be installed to play or to run the tests:
#     python run_game.py
#     python -m unittest discover -s tests -t . -v
#
# The optional LLM features talk to Ollama / LM Studio / Anthropic / OpenAI over plain
# HTTP (urllib), so they need no client libraries either. See docs/ai_content_roadmap.md.
